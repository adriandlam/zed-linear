# Linear

Linear light and dark theme for Zed, ported from Codex.

Includes:

- Linear Light
- Linear Dark

## Local Install

Copy `themes/linear.json` to `~/.config/zed/themes/linear.json`, then select `Linear Light` or `Linear Dark` in Zed.

## Marketplace

Publish this folder as `adriandlam/linear`, then add it as a submodule in `zed-industries/extensions`.
